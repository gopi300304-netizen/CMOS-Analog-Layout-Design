# Analog CMOS Layout Design

## About This Repository

This repository contains my analog CMOS circuit design and layout implementations as part of my VLSI learning journey.

The projects focus on understanding analog circuit fundamentals, transistor-level implementation, and CMOS layout design.

## Projects

The following circuits are included:

1. Low Dropout Regulator (LDO)
2. Bandgap Reference (BGR)
3. Operational Amplifier (Op-Amp)

## Tools Used

- Cadence Virtuoso

## Technology

- Process Node: 45 nm
- PDK: GPDK45
- Technology: CMOS

## Key Learning Areas

- CMOS Fundamentals
- NMOS and PMOS Transistor Design
- Analog Circuit Design
- Schematic Design
- Layout Design
- Device Matching Techniques
- Common-Centroid and Interdigitation Techniques
- Guard Ring Implementation
- Design Rule Check (DRC)
- Layout Versus Schematic (LVS)
